Buyers place an order and then don’t complete the payment — the card fails, they get distracted, they want to ask a question first. Each of these orders is a warm buyer, but reminding them depended on someone having time to do it by hand.

Buyers in the region expect to talk on WhatsApp, not email.

{% endblock %} {% block built %}
  • Shopify → Kommo: new and unpaid orders become deals in the CRM pipeline with all order details.
  • n8n follow-up flow: on a schedule, unpaid orders trigger a WhatsApp message through the official WhatsApp Cloud API from the store’s business number.
  • AI agent to answer buyers’ questions in the conversation that follows.
{% endblock %} {% block status %}

The flow runs in production on a self-hosted n8n. The store is on managed services: I monitor the flow, adjust message timing and texts, and extend the automation as the store adds channels.
